# Code of conduct

Everyone participating in Habits issues, pull requests and other project spaces is expected to treat others with respect, regardless of background or experience.

- Discuss ideas and code constructively. Explain disagreements and accept good-faith corrections.
- Avoid harassment, threats, discriminatory language, sexual attention and personal attacks.
- Do not publish another person's private information or pressure them to disclose it.
- Respect maintainers' scope decisions and the time of other contributors.

The maintainer, [@KingKord](https://github.com/KingKord), may edit or remove content, close discussions, or restrict participation to protect the community. Responses should be proportionate to the behavior and its impact.

Report a concern to the maintainer through a private channel you already share. If none is available, open an issue titled "Private contact requested" without names, allegations or other sensitive details and ask for a private reporting route. Do not post a sensitive incident report publicly. No guaranteed response time is offered.

These expectations apply to project spaces and to people representing the project elsewhere.
