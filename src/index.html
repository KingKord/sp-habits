Habit settings and reduction plans
About the calendar

Select a habit entry within a day to edit its amount. The daily amount appears next to the name; the circle colour shows the result over the goal period. On a narrow screen, select a date to see its habits below the month. Today has a dashed outline and its result is provisional. Future days and days outside tracking are not assessed.

Ideal is the desired goal; yellow means the limit or minimum is met. Red means the maximum was exceeded or the minimum was missed. Ideal and yellow days are successful. Periods longer than a day include earlier events in a rolling interval.

Gradual reduction

Set the date, quantity and number of days for each stage. For example: 1 per 2 days → 1 per 7 days. Each stage must reduce the average frequency.

How it works

Good habits meet a minimum. Bad habits stay within a limit. Today's result is provisional. Missing quantities count as zero; unmarked check-ins stay unknown and are excluded from the success rate.

Select a habit name for settings or an amount to edit the daily total. The ± buttons use the configured step. Periods longer than one day are rolling intervals that include the selected day.

Use ✓ or × to report a check-in result: Done / Missed for Good, No slip / Slipped for Bad. Select the chosen result again to undo it and leave the day unmarked. No actual completion time is recorded.

Data is stored in Super Productivity. Use Export JSON for backups. Editing from multiple devices at the same time is not supported.
